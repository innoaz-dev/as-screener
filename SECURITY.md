# 보안 문제 알리기 / Reporting security issues

탐지를 우회하는 문장, 재작성 단계를 통과하는 숨은 지시, 로컬 화면의 취약점 같은 보안 문제는 **공개 Issue에 올리지 마세요.** 공개되면 공격하는 쪽이 바로 쓸 수 있습니다.

이 저장소의 **Security** 탭 → **Report a vulnerability** 로 비공개로 알려 주세요.

Please do **not** open a public issue for security problems such as phrasings that bypass detection, hidden instructions that survive rewriting, or vulnerabilities in the local web form. Use **Security → Report a vulnerability** in this repository to report privately.
