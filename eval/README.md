> ⚠️ 탐지 시험용으로 일부러 쓴 **악성 지시 문장**이 들어 있습니다. 스킬이나 프롬프트에 넣지 마세요.

| 파일 | 내용 | 쓰는 법 |
|---|---|---|
| `practice.jsonl` | 연습 세트 306줄 (한·중·일 각 공격 72 + 정상 30) | 규칙을 고칠 때 놓친 문장·오탐 문장을 보면서 씀 |
| `heldout.jsonl` | 시험 세트 270줄 (한·중·일 각 공격 60 + 정상 30) | **점수만 봄.** 문장을 읽거나 이걸 보고 규칙을 고치지 않음 |

두 세트 모두 규칙을 모르는 별도 작성자(Claude 하위 에이전트)가 썼습니다. 공격 6종(override, conceal, stealth, jailbreak, cred_access, exfil)과, 같은 단어를 쓰는 정상 문장(부정문, 보안 문서, 정책, 개발 지시 등)으로 구성됩니다.

```powershell
uv run --python 3.12 --with yara-python tools\measure_recall.py            # 연습 세트
uv run --python 3.12 --with yara-python tools\measure_recall.py heldout    # 시험 세트 (점수만)
```
